# avlink

`avlink` is a Python script which adds hyperlinks to a _Halls of Arden Vul_ PDF.
It scans the document for references to areas, entities, and other elements, and
creates clickable links to their respective locations within the PDF.

Text like "1-4" is ambiguous: it could be a reference to area 1-4, or a range
of numbers used for some other purpose (damage, a die roll, a quantity, a
roll-table row, etc.). To resolve these, `avlink` reads a prebuilt
disambiguation index (`area_index.txt`) that records, per occurrence, whether
to treat the token as a reference or a number. See
[Disambiguation index](#disambiguation-index) below. If the index is absent,
`avlink` falls back to context heuristics alone, which are less accurate.

It contains no material from _Halls of Arden Vul_ beyond a few words and short
phrases used to locate entries and disambiguate references. You must already
own the PDF for this script to do anything. You can purchase a copy from
[DriveThruRPG](https://www.drivethrurpg.com/en/product/307320/the-halls-of-arden-vul-complete).

Note that this script was designed to work on the complete document which
compiles all volumes. I do not have the individual volumes so cannot test
whether it works on them. At any rate, the combined document would work much
better as there are numerous links between volumes.

## How to use

If you're comfortable with the command line and using Python:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
./avlink.py --help
```

If you're not, and you're running Windows, you can download an executable from
the [Releases](https://github.com/orodley/avlink/releases) section of this
repository. Once obtained you can drag your PDF onto the `avlink.exe`
executable, and it will create the linked PDF.

## Disambiguation index

`area_index.txt` resolves the ambiguous "is `1-4` an area or a number?" cases.
Each line is one occurrence of an ambiguous token, with a decision:

```
# page  ordinal  token  decision
206     1        1-3    range
211     0        3-18   range
127     0        2-8    ref
```

`ref` makes a link, `range` makes none. The decision is authoritative, so **if
you spot a wrong link (or a missing one), just flip `ref`/`range` on that line
and re-run `avlink`** -- no code changes needed. Only ambiguous tokens that the
heuristics would otherwise link appear here; unambiguous references are always
linked.

The shipped index is good enough that most users never need to touch it. It was
generated by combining the context heuristics with a second opinion from a local
LLM, keeping a link only when **both** agree it's a reference. On a
150-occurrence hand-labelled sample this raised link precision from 0.89 to 0.97
while holding recall at ~0.99. The decisions are baked into the file, so running
`avlink` needs no LLM and keeps its only real dependency on PyMuPDF.
